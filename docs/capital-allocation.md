# 資金配置功能 — 程式邏輯文件

報表「匯出」後方的「資金配置」按鈕：讀取每日上傳的「未實現損益」Excel
（預設工作表），依階段滾動加碼規則計算各持股的可投入資金，匯出
`資金配置_MMDD.xlsx`。

程式位置：`template.html` 與 `index.html` 內
`// capital-allocation-logic-start` ～ `// capital-allocation-logic-end`
區塊（兩檔內容一致，修改需同步）。回歸測試：`tests/test_capital_allocation.cjs`。

## 1. 使用流程

1. 點「資金配置」→ 彈出對話框（`capitalAllocOverlay`）。
2. 檔案總管選擇未實現損益 Excel（`.xlsx`）。
3. 顯示「股票投資上限」，預設 `2,000,000`，可修改。
4. 點「匯出資金配置」→ 前端解析 → 下載 `資金配置_MMDD.xlsx`。

全程在瀏覽器端完成，不上傳伺服器；需支援 `DecompressionStream`
的瀏覽器（Chrome / Edge 80+）。

## 2. 輸入檔格式（未實現損益 Excel）

預設工作表（第一個 sheet），標頭列需包含以下欄名（容許空白差異）：

| 欄 | 欄名 | 用途 |
| --- | --- | --- |
| B | 商品名稱 | 取開頭代碼比對報表 KD（如 `2330 台積電`） |
| F | 投資成本 | 反推已執行階段、計算可投入資金 |
| H | 損益率 | 判定階段（小數，-0.05 = -5%） |
| G | 損益 | 損益率缺漏時以 損益 ÷ 投資成本 推算 |

「小計／合計」列原樣保留、不計算。其餘欄位原樣帶出。

## 3. 輸出 Excel

保留原檔 A～I 欄，附加三欄：

| 欄 | 標題 | 內容 |
| --- | --- | --- |
| J | KD值 | 依代碼比對報表資料，顯示最新 `K xx / D xx`；ETF、債券或不在報表內的標的留空 |
| K | 階段 | `0`～`4`；已執行標「（已執行）」，階段 4 標「（停止加碼）」 |
| L | 可投入資金 | 數值；已執行或停止加碼時空白 |

## 4. 階段滾動判斷邏輯

初始已在 KD 低檔買入 20 萬（階段 0）。

| 階段 | PL 條件 | 追加金額 | 累計目標 |
| --- | --- | --- | --- |
| 0 | PL > -5% | 不加碼 | 20 萬 |
| 1 | PL ≤ -5%，且此階段未執行 | 20 萬 | 40 萬 |
| 2 | PL ≤ -10%，且此階段未執行 | 40 萬 | 80 萬 |
| 3 | PL ≤ -15%，且此階段未執行 | 60 萬 | 140 萬 |
| 4 | PL ≤ -20% | 最大容許虧損，停止加碼 | — |

### 4.1 目前階段 S（`capitalStageForPL`）

- 依損益率取**最深**階段：PL -12% 直接落階段 2，不經過階段 1。
- PL ≤ -20% → 階段 4，停止加碼。
- 損益率缺漏或無法解析 → 階段空白，不計算。

### 4.2 已執行階段 E（`executedStageFromCost`）

由投資成本反推，不需上傳上次損益檔：

```
E = 最大的 n，使得 投資成本 ≥ 累計目標[n] × 0.9
```

- 累計目標：階段 0 = 20 萬、1 = 40 萬、2 = 80 萬、3 = 140 萬。
- 0.9 為容許誤差：實際下單按整股／整張，金額不會剛好是整數目標。
- 例：成本 522,678 ≥ 40 萬×0.9 但未達 80 萬×0.9 → E = 1。

### 4.3 可投入資金（`allocatableAmount`，B 方案：補齊累計目標）

僅當 `1 ≤ S ≤ 3` 且 `S > E`（此階段未執行）時計算：

```
可投入資金 = max(0, min(累計目標[S], 股票投資上限) − 投資成本)
```

- **補齊累計水位**：成本 20 萬只買初始、PL -12% 落階段 2
  → 補 60 萬（80 萬 − 20 萬），跳過的階段 1 一併補齊。
- 成本 522,678（E=1）、落階段 3 → 補 877,322（140 萬 − 522,678）。
- 成本已達該階段累計目標 → 視為已執行，可投入空白。
- 上限低於累計目標時以上限為天花板；上限設 0 或留空表示不設限。

## 5. 限制與人工判斷

- 成本超過 140 萬的舊有大部位自動視為全階段已執行，不再加碼。
- 曾**賣出減碼**的標的，成本下降會誤判為未執行 → 請人工略過。
- 初始買入非 20 萬的標的，已執行階段推斷會偏差。
- 「已執行」是以成本推斷的近似值，非實際下單紀錄。

## 6. 程式結構

| 函式 | 職責 |
| --- | --- |
| `capitalStageForPL(plRatio)` | 損益率 → 目前階段 S（含停止加碼） |
| `executedStageFromCost(investCost)` | 投資成本 → 已執行階段 E |
| `allocatableAmount(investCost, stage, limit)` | 補齊累計目標的可投入資金 |
| `holdingCodeFromName(value)` | 商品名稱 → 股票代碼 |
| `plRatioFromCell(value)` | 解析損益率（小數或 `%` 字串） |
| `capitalAllocCellXml(value, ref)` | 產出儲存格 XML（數值用 `<v>`，科學記號正規化） |
| `buildCapitalAllocWorksheet(rows, limit, kdLookup)` | 組出完整 worksheet XML 與持股筆數 |
| `capitalAllocKdText(code)` | 代碼 → 報表最新 `K xx / D xx` |
| `unzipXlsxEntries` / `inflateZipEntry` / `readXlsxFirstSheetRows` | 純前端 xlsx 讀取（ZIP + deflate + XML） |
| `excelWorkbookFiles` / `downloadExcelFile` | 與「匯出」共用的 xlsx 打包下載 |
